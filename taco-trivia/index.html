How it plays

One board, one operator

There is no student app at all. The teacher is the only person who touches the game, which is what lets a class start in seconds.

  • Scoring is the teacher's: plus and minus buttons, or type an exact score.
  • Three answer styles to suit the class: Fast & Loud, Take Turns and Quiet Mode.
  • An optional question timer from 1 to 600 seconds, with a short beep made in the browser.
  • Special cards look like any other tile until opened; the teacher applies the effect, such as switching or stealing points.
  • A game in progress survives a page reload.
Under the hood

How it is built, and what it lacks

Games are built in an admin grid editor: categories, point values, questions, and images stored with the game. Free games are readable by anyone; a premium game is sent only after the Class Cookies platform confirms the teacher has subscribed.

Moving the server to Seoul in September cut the games list's response from about a second to about a third of a second, by the project's own before-and-after notes. Measured on 7 October, the setup page scored 100 for Lighthouse Performance on desktop and 95 on mobile; the home page, which loads a cover image for every game, 96 and 82.

Honest gaps

  • No automated test suite. Changes are checked with scripted browser runs and before-and-after screenshots, not unit tests.
  • Lint has no errors (two warnings), and the production build of the current version passed on Vercel.
  • The screens on this page use Happy Shuffle Kids, a free pack with text-only questions.
