Cookie Code

A word-guessing game for the whole class on one screen. The teacher sets a secret word; the class calls out guesses, the teacher types them, and the tiles show which letters are right.

A small first version

Cookie Code was written in one evening, 15 September 2026, from a design handed over beforehand: eight commits, each with a Claude co-author line. It has had no changes since.

By design it has no teams, scores or sound, and keeps nothing between visits. The game rules live outside the screens so the tests can check them, including the standard rules for repeated letters.
