How I work

I decide what gets built. AI agents write the code.

I'm the product owner and designer. I decide what to build and why, design how it works in a real classroom, write the specifications and rules, and set the tests and checks that every change has to pass. Nothing is released until I say so.

The code is written by AI coding agents. 59 Seconds started in June 2026 as a scaffold generated by Lovable; since then Claude Code has written the code for all six products, working in small steps that I approve, while two chat-based review agents check the same work and I compare what they find.

On the production branches, 694 of the 869 commits carry a Claude co-author line. Git lists me as the author because I direct the agents and commit their work; it does not mean I typed the code.

The products themselves contain no AI: none of them calls an AI service.

  1. I set the brief: what to build, the rules, and a success criterion for each step.
  2. The agent plans and stops for my approval before it edits anything.
  3. It builds in small steps. A new test has to fail first; done means typecheck, lint, tests and a production build all pass.
  4. Two review agents check the same work; I pass each one the other's findings.
  5. I decide and release, check the live site, and use the result in class.
